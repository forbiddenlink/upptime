## How this repo works

- **Monitors:** the sites to check live in `.upptimerc.yml` (34 at the time of writing). The table above is generated by Upptime and is overwritten on each run; edit `.upptimerc.yml`, not the table.
- **Schedules:** uptime checks and issue updates run every 5 minutes; summary and graphs run daily at 00:00 UTC, response time at 23:00 UTC, the static site at 01:00 UTC, and the Upptime template update monthly (`workflowSchedule` in `.upptimerc.yml`).
- **Incidents:** Upptime opens a GitHub issue when a site goes down and closes it on recovery.
- **Status page:** published at <https://status.elizabethannstein.com> from the `gh-pages` branch.
- **Coverage audit:** `.github/workflows/coverage-audit.yml` runs weekly (Mondays 07:23 UTC) and lists public repos whose homepage is not monitored, using `scripts/coverage_audit.py`. Run its tests with `python3 -m unittest discover -s tests`.
- **Supabase keep-alive:** `.github/workflows/supabase-keepalive.yml` queries two Supabase-backed apps daily so their free-tier projects are not paused.
